Bible Quest: The Lost Clues — Adult Edition v0.3
聖經時空冒險：失落的線索 — 成人版第一站

Play locally / 本機試玩
- Open index.html in Chrome / Edge / Safari.
- World map is the homepage. Click marker 1 to enter Tour 1.
- The five zones contain interdependent investigation puzzles.
- Use the 中文 / EN control to switch languages.
- Local progress is saved when browser storage permits.

Publish / 網頁發布
- Upload index.html to a new GitHub repository root.
- In Settings > Pages, deploy from the main branch and root folder.
- Everything is embedded in index.html, including both map images.

Important / 注意
- Tours 2–6 are placeholders, not playable.
- Bible narrative references: Genesis 6:15–16; 7:11; 8:4–14; 9:8–17.
- The map and mechanisms are artistic/fictional; they are not archaeology or claims about Biblical artifacts.
- Designed as an adult investigation puzzle prototype, not a fully animated role-playing game.
